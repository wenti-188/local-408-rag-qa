# 计算机面试高频八股文 核心考点
## 计算机网络 面试高频题
- 题：TCP和UDP的区别？应用场景？ 答案：TCP面向连接、可靠传输、有拥塞控制、开销大，用于文件传输、网页；UDP无连接、不可靠、开销小、时延低，用于实时音视频、直播、DNS。
- 题：从输入URL到页面显示发生了什么？ 答案：DNS解析域名→建立TCP连接→发HTTP请求→服务器处理返回响应→浏览器解析HTML渲染页面，整个过程涉及网络分层、TCP握手、HTTP协议。
- 题：浏览器输入URL后TCP三次握手过程？ 答案：客户端发SYN→服务端回SYN+ACK→客户端发ACK，连接建立，三次是为了防止旧的失效请求导致服务端浪费资源。
- 题：HTTPS是怎么加密的？ 答案：用对称加密传输数据，用非对称加密交换对称密钥，结合两者的优点，解决明文传输被窃听的问题。
- 题：状态码301和302的区别？ 答案：301是永久重定向，浏览器会缓存；302是临时重定向，每次都重新请求原地址。
## 操作系统 面试高频题
- 题：进程和线程的区别？ 答案：进程是资源分配的最小单位，线程是CPU调度的最小单位；进程有独立地址空间，线程共享进程的地址空间；进程切换开销大，线程切换开销小。
- 题：进程间通信的方式有哪些？ 答案：管道、消息队列、共享内存、信号量、套接字，其中共享内存速度最快，因为不需要内核态用户态的数据拷贝。
- 题：线程同步的方式有哪些？ 答案：互斥锁、条件变量、读写锁、信号量，用来解决多线程共享资源的竞态条件问题。
- 题：死锁的四个必要条件？ 答案：互斥、占有且等待、不可抢占、循环等待，破坏任意一个条件就能预防死锁。
- 题：用户态和内核态的区别？ 答案：内核态可以执行任意指令，直接访问硬件；用户态只能受限访问资源，要通过系统调用进入内核态。
## 编程语言核心知识点
### C语言
- C语言是面向过程的编译型语言，直接操作内存，运行效率高，是操作系统、嵌入式开发的主流语言。
- C语言的指针是存储内存地址的变量，指针操作可以直接访问内存，数组名是首元素的地址常量，不能自增自减。
- C语言内存分区：栈区（存局部变量，函数返回自动释放）、堆区（malloc申请，手动free释放）、全局区（存全局变量和静态变量）、代码区（存程序指令）。
- malloc申请的内存要手动free，否则会内存泄漏；free之后要把指针置空，避免野指针。
### C++
- C++是在C语言基础上扩展的面向对象语言，支持封装、继承、多态，兼容C语言的大部分特性。
- C++的多态是通过虚函数实现的，虚函数表存每个类的虚函数地址，运行时根据实际对象类型调用对应的函数。
- C++的智能指针：unique_ptr独占所有权，shared_ptr共享引用计数，weak_ptr解决循环引用问题，用来自动释放堆内存，避免内存泄漏。
### Java
- Java是跨平台的面向对象语言，编译成字节码在JVM上运行，一次编译到处运行，有自动垃圾回收机制。
- Java的JVM内存分区：堆（存对象实例，垃圾回收的主要区域）、栈（存栈帧、局部变量）、方法区（存类信息、常量）、程序计数器。
- Java的基本数据类型：byte、short、int、long、float、double、char、boolean，引用类型是类、数组、接口。
- Java面向对象三大特性：封装、继承、多态，继承是子类获得父类的属性和方法，多态是同一接口不同对象有不同的实现。
### Python
- Python是解释型动态类型语言，语法简洁，开发效率高，广泛用于数据分析、AI、Web开发、爬虫。
- Python的列表是可变序列，元组是不可变序列，字典是键值对结构，集合是无序不重复的元素集合。
- Python的GIL（全局解释器锁）保证同一时刻只有一个线程执行Python字节码，所以Python多线程不适合CPU密集型任务，适合IO密集型任务。
- Python装饰器是用来在不修改原函数代码的情况下扩展函数功能，本质是接收函数作为参数，返回新函数的高阶函数。
## 数据库 面试高频考点
- MySQL是最常用的关系型数据库，用表结构存储数据，支持SQL查询，支持事务、索引、外键。
- 索引是加快查询速度的数据结构，MySQL默认用B+树做索引，索引能加快查询速度，但是会降低写入速度，占用额外存储。
- 事务的ACID特性：原子性（事务要么全做要么全不做）、一致性（事务前后数据一致）、隔离性（并发事务之间互不干扰）、持久性（事务提交后数据永久保存）。
- 事务隔离级别：读未提交、读提交、可重复读、串行化，MySQL默认是可重复读级别，解决幻读问题。
- 内连接、左连接、右连接的区别：内连接取两表交集，左连接取左表全部记录，右连接取右表全部记录。
## Web开发 核心考点
- HTTP是无状态协议，用Cookie/Session维持用户登录状态，Cookie存在客户端，Session存在服务端。
- GET和POST请求的区别：GET参数在URL里，长度有限，幂等；POST参数在请求体里，长度无限制，不幂等。
- 前端三要素：HTML写结构，CSS写样式，JavaScript写交互，浏览器解析HTML渲染成页面。
- RESTful API是一种接口设计风格，用HTTP动词（GET/POST/PUT/DELETE）表示操作，用URL表示资源，接口简洁规范。
## 机器学习 核心知识点
- 机器学习是让计算机从数据中学习规律，不需要显式编程，分为监督学习、无监督学习、强化学习。
- 监督学习的典型任务是分类和回归，用带标签的数据训练模型，预测新数据的标签；无监督学习是聚类，从无标签数据中发现结构。
- 过拟合是模型在训练集上表现好，测试集上表现差，解决方法是增加数据、正则化、早停、 dropout。
- 常见评估指标：准确率、精确率、召回率、F1值、AUC，用来衡量分类模型的性能。
## 深度学习 核心知识点
- 深度学习是基于神经网络的机器学习方法，多层神经网络可以自动提取数据的特征，不需要人工设计特征。
- 神经网络的基本单元是神经元，接收输入加权求和，经过激活函数输出，常见激活函数有ReLU、Sigmoid、Tanh。
- 反向传播算法是通过链式求导，从输出层往输入层逐层更新网络权重，是神经网络训练的核心算法。
- 常见深度学习模型：CNN（卷积神经网络，用于图像）、RNN/LSTM（循环神经网络，用于序列数据）、Transformer（现在大模型的基础结构）。
