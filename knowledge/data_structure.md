# 数据结构核心考点（详细版）

## 基本概念
- 数据结构是相互之间存在一种或多种特定关系的数据元素的集合，包括逻辑结构和物理结构。
- 逻辑结构：线性结构（线性表、栈、队列）和非线性结构（树、图、集合）。
- 物理结构（存储结构）：顺序存储、链式存储、索引存储、散列存储。
- 算法的五个特性：有穷性、确定性、可行性、输入、输出。
- 算法复杂度：时间复杂度和空间复杂度，用大O表示法描述。常见复杂度排序：O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)。

## 线性表
- 顺序表：用连续的内存单元存储线性表元素，支持随机访问，随机访问时间复杂度O(1)；插入删除平均需要移动n/2个元素，时间复杂度O(n)；存储密度高，但是插入删除需要移动大量元素，扩容需要重新申请内存。
- 单链表：节点由数据域和指针域组成，不支持随机访问，查找节点时间复杂度O(n)；已知节点位置时插入删除操作时间复杂度O(1)，只需要修改指针；不需要预先分配内存，扩容灵活。
- 双链表：节点有前驱和后继指针，可以双向遍历；插入删除时需要同时修改两个方向的指针。
- 循环链表：尾节点的指针指向头节点，从任意节点出发都能遍历整个链表。
- 静态链表：用数组描述的链表，数组的每个元素存数据和下一个元素的数组下标。

## 栈和队列
- 栈：后进先出(LIFO)的线性表，只能在栈顶进行插入删除操作。栈的典型应用：函数调用栈、括号匹配、表达式求值、递归转非递归、深度优先搜索。
- 队列：先进先出(FIFO)的线性表，只能在队尾插入，队头删除。队列的典型应用：广度优先搜索、操作系统进程调度、打印任务队列。
- 顺序队列的假溢出：队头指针不断后移，队尾指针到达数组尾部，但数组前面还有空闲空间；解决方法是循环队列。
- 循环队列：把顺序队列的逻辑空间看成环，队空条件是front==rear，队满条件是(rear+1)%MaxSize==front，牺牲一个存储单元区分队空和队满；队列长度=(rear-front+MaxSize)%MaxSize。
- 栈的顺序存储：栈底固定在数组低端，栈顶指针top指向栈顶元素的下一个位置；进栈top++，出栈top--。

## 树与二叉树
- 树的基本概念：根节点、叶子节点、度（节点的子树个数）、深度（根节点到节点的层数）、高度（节点到叶子节点的最长路径长度）。
- 二叉树：每个节点最多两个子树，分左子树和右子树，次序不能颠倒。
- 二叉树的性质：
  1.  第i层最多有2^(i-1)个节点。
  2.  高度为h的二叉树最多有2^h -1个节点。
  3.  度为0的叶子节点数n0，度为2的节点数n2，则n0 = n2 + 1。
- 满二叉树：高度为h，有2^h -1个节点，每一层节点数都达到最大值。
- 完全二叉树：高度为h，前h-1层是满二叉树，最后一层节点靠左连续排列；n个节点的完全二叉树高度为⌊log2(n)⌋ +1。
- 二叉树的存储：顺序存储适合完全二叉树，按层序编号存数组；二叉链表是最常用的存储方式，每个节点存数据、左孩子指针、右孩子指针。
- 二叉树遍历：
  - 前序遍历：根→左→右
  - 中序遍历：左→根→右
  - 后序遍历：左→右→根
  - 层序遍历：从上到下、从左到右逐层遍历
- 由前序遍历+中序遍历可以唯一确定一棵二叉树；由后序遍历+中序遍历也可以唯一确定一棵二叉树；只知道前序和后序不能唯一确定。
- 线索二叉树：利用二叉树的空指针域，存放节点在某种遍历次序下的前驱和后继节点指针，加快查找速度。
- 哈夫曼树：带权路径长度(WPL)最小的二叉树，没有度为1的节点；n个叶子节点总节点数是2n-1；哈夫曼树中权值越大的叶子离根越近。哈夫曼编码是前缀编码，用于数据压缩。
- 二叉搜索树(BST)：左子树所有节点值小于根节点，右子树所有节点值大于根节点；中序遍历得到递增有序序列；查找平均时间复杂度O(logn)，最坏退化成链表O(n)。
- 平衡二叉树(AVL树)：任意节点左右子树的高度差绝对值不超过1；插入删除后通过旋转保持平衡，查找平均时间复杂度O(logn)，最坏也是O(logn)。
- B树：m阶平衡多路查找树，每个节点最多有m个子树，除根节点外每个节点关键字数范围是⌈m/2⌉ -1到m-1；所有叶子节点在同一层。
- B+树：B树的变形，非叶子节点只存索引，所有数据都存在叶子节点，叶子节点之间用指针相连，适合数据库和文件系统的索引。

## 图
- 图的基本概念：有向图、无向图、完全图、度（无向图）、入度/出度（有向图）、路径、路径长度、连通图、连通分量。
- 图的存储：
  - 邻接矩阵：用二维数组存顶点之间的边，空间复杂度O(n²)，适合稠密图；可以快速判断两个顶点之间有没有边。
  - 邻接表：为每个顶点建一个单链表存它的邻接点，空间复杂度O(n+e)，适合稀疏图。
- 图的遍历：
  - DFS深度优先搜索：类似树的前序遍历，用栈实现，一条路走到黑再回溯。
  - BFS广度优先搜索：类似树的层序遍历，用队列实现，一层一层往外扩展。
- 最小生成树：连通无向图中，包含所有顶点、边权值和最小的生成树。
  - Prim算法：从一个顶点开始，每次选距离当前集合最近的顶点加入，时间复杂度O(n²)，适合稠密图。
  - Kruskal算法：把所有边按权值排序，从小到大选边，不构成环就加入生成树，时间复杂度O(eloge)，适合稀疏图。
- 最短路径：
  - Dijkstra算法：求单源最短路径，每次选距离源点最近的未确定顶点加入集合，不能处理带负权边的图，时间复杂度O(n²)。
  - Floyd算法：求所有点对之间的最短路径，动态规划思想，时间复杂度O(n³)，可以处理带负权边的图。
- 拓扑排序：针对有向无环图(DAG)，每次选入度为0的顶点输出，删除它的出边，重复直到所有顶点输出；如果不能输出所有顶点，说明图中有环。拓扑排序用于判断工程是否有循环依赖。
- AOE网与关键路径：关键路径是从源点到汇点的最长路径，关键路径上的活动是关键活动，决定整个工程的最短完成时间。

## 查找
- 顺序查找：从头到尾逐个比较，平均时间复杂度O(n)。
- 折半查找（二分查找）：只适用于有序顺序表，每次和中间元素比较，缩小一半查找范围，时间复杂度O(logn)。
- 分块查找：把表分成若干块，块间有序、块内无序，先确定块再块内查找，性能介于顺序查找和折半查找之间。
- 散列表（哈希表）：通过哈希函数把关键字直接映射到存储地址，理想情况下查找时间复杂度O(1)。
  - 哈希冲突解决方法：开放定址法（线性探测、二次探测）、链地址法（把哈希值相同的元素串成链表）。
  - 装填因子=表中元素个数/哈希表长度，装填因子越大，冲突概率越高。

## 排序
- 插入排序：
  - 直接插入排序：每次把一个元素插入前面已经排好序的序列中，平均时间复杂度O(n²)，稳定，空间复杂度O(1)。
  - 希尔排序：把序列按下标增量分组，每组做直接插入排序，逐渐缩小增量，时间复杂度约O(n^1.3)，不稳定。
- 交换排序：
  - 冒泡排序：相邻元素两两比较，逆序就交换，每趟把最大的元素“冒泡”到最后，平均时间复杂度O(n²)，稳定。
  - 快速排序：选一个基准元素，把序列分成比基准小和比基准大的两部分，递归排序两部分；平均时间复杂度O(nlogn)，最坏情况（数组已经有序）O(n²)，不稳定，是内部排序中平均性能最好的算法。
- 选择排序：
  - 简单选择排序：每趟选最小的元素和当前位置交换，时间复杂度O(n²)，不稳定。
  - 堆排序：利用堆结构，建大根堆，每次把堆顶最大元素和堆尾交换，调整堆，时间复杂度始终O(nlogn)，空间复杂度O(1)，不稳定。
- 归并排序：把序列分成两半，递归排序两半，再合并成一个有序序列，时间复杂度始终O(nlogn)，稳定，需要O(n)的辅助空间。
- 基数排序：按关键字的各位进行分配和收集，不需要比较关键字大小，时间复杂度O(d(n+r))，稳定，适合关键字位数少的序列。
- 稳定性总结：稳定的排序包括冒泡排序、直接插入排序、归并排序、基数排序；不稳定的排序包括快速排序、简单选择排序、希尔排序、堆排序。
