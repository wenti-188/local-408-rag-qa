# 计算机组成原理核心考点

## 计算机系统概述
- 冯·诺依曼计算机的核心思想：存储程序、指令和数据以同等地位存放在存储器中，计算机按地址顺序访问指令；五大组成部件：运算器、控制器、存储器、输入设备、输出设备。
- 计算机性能指标：
  - 主频（CPU时钟频率）：单位Hz，主频越高时钟周期越短。
  - CPI：执行每条指令需要的平均时钟周期数。
  - MIPS：每秒执行多少百万条指令，MIPS = 主频/(CPI*1e6)。
  - MFLOPS：每秒执行多少百万次浮点运算，用来衡量计算机浮点计算性能。

## 数据表示与运算
- 进制转换：二进制、八进制、十六进制、十进制之间的相互转换。
- 原码、反码、补码：正数的原码反码补码相同；负数的反码是原码符号位不变其余位取反，补码是反码+1；补码的0表示唯一，扩展表示范围比原码反码多一个最小负数。
- 定点数：定点整数小数点固定在最低位后面；定点小数小数点固定在符号位后面。
- 浮点数：由阶码和尾数组成，阶码的位数决定表示范围，尾数的位数决定表示精度；IEEE754标准是最常用的浮点数标准。
- 定点运算：
  - 加法：两个数补码相加，符号位一起参与运算，结果的符号位自然得到；溢出判断：两个正数相加结果为负，或两个负数相加结果为正，就发生溢出。
  - 移位运算：算术移位对有符号数操作，符号位保持不变；逻辑移位对无符号数操作，空位补0。
- 浮点数的加减运算步骤：对阶、尾数求和、规格化、舍入、溢出判断；对阶原则是小阶向大阶看齐。

## 存储器层次结构
- 存储器层次：寄存器 → Cache → 主存 → 辅存；速度越来越慢、容量越来越大、单位成本越来越低。
- 存储器的分类：按读写方式分为随机存取存储器(RAM)和只读存储器(ROM)；RAM断电丢失数据，ROM断电不丢失数据。
- 主存编址：地址线的位数决定寻址空间大小，n根地址线可以寻址2^n个存储单元。
- Cache（高速缓冲存储器）：解决CPU和主存速度不匹配的问题，存放主存中CPU近期会频繁访问的内容局部副本；基于程序访问的局部性原理（时间局部性、空间局部性）工作。
- Cache映射方式：直接映射（每个主存块只能固定放到一个Cache行）、全相联映射（任意位置）、组相联映射（折中方案）。
- Cache命中率：命中率越高，平均访问时间越接近Cache速度；Cache和主存之间的地址映射由硬件自动完成，对程序员透明。
- 虚拟存储器：由主存和辅存共同组成，由操作系统和硬件配合完成，给用户提供比实际主存大得多的逻辑地址空间。

## 指令系统
- 指令格式：操作码字段 + 地址码字段；操作码说明做什么操作，地址码说明操作数在哪。
- 寻址方式：
  - 立即寻址：地址码字段本身就是操作数，速度最快。
  - 直接寻址：地址码字段是操作数的有效地址。
  - 间接寻址：地址码字段是操作数有效地址所在主存单元的地址。
  - 寄存器寻址：操作数在寄存器里，速度快。
  - 基址寻址：基址寄存器内容加形式地址形成有效地址，适合多道程序设计。
  - 变址寻址：变址寄存器内容加形式地址形成有效地址，适合数组遍历。
- CISC（复杂指令集）：指令数量多、长度不固定、寻址方式多，代表是x86架构；RISC（精简指令集）：指令数量少、长度固定、寻址方式少、大部分指令单周期完成，代表是ARM架构。

## CPU
- CPU由运算器和控制器组成：运算器负责数据运算，控制器负责取指令、译码、发控制信号。
- 指令周期：取指令 → 间址周期 → 执行周期 → 中断周期，一个指令周期可能包含多个机器周期，一个机器周期包含多个时钟周期。
- 指令流水线：把一条指令的执行过程分成多个子阶段，不同子阶段重叠执行，提高指令吞吐率；流水线冒险包括结构冒险、数据冒险、控制冒险；流水线的加速比等于顺序执行时间除以流水线执行时间。

## 总线与I/O
- 总线：连接各个部件的公共信息传输线，分为数据总线（宽度决定一次传输数据位数）、地址总线（宽度决定寻址空间）、控制总线。
- I/O控制方式：程序查询方式（CPU轮询设备状态，效率最低）、程序中断方式（设备准备好后发中断信号通知CPU）、DMA方式（直接存储器访问，设备和主存之间直接传输数据，不需要CPU干预，以数据块为单位）。
- 中断：CPU收到中断信号后暂停当前程序，转去执行中断服务程序，处理完后回到原来的程序继续执行；中断响应是在每条指令执行周期结束后检查是否有中断请求。
