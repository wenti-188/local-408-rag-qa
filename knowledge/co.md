# 计算机组成原理核心考点（详细版）

## 计算机系统概述
- 冯·诺依曼计算机的核心思想：存储程序，指令和数据存放在存储器中，计算机按地址顺序自动执行指令。五大组成部件：运算器、控制器、存储器、输入设备、输出设备。
- 计算机的层次结构：微程序机器级、传统机器级、操作系统级、汇编语言级、高级语言级。
- 计算机性能指标：
  - 主频/时钟周期：主频是CPU每秒的时钟脉冲数，时钟周期=1/主频。
  - CPI：执行每条指令需要的平均时钟周期数。
  - MIPS：每秒执行多少百万条指令，MIPS = 主频/(CPI×10^6)。
  - MFLOPS：每秒执行多少百万次浮点运算，衡量浮点计算性能。
  - 数据通路带宽：数据总线一次能并行传送的位数。
- 计算机的分类：按信息规模分巨型机、大型机、小型机、微型机；按指令系统分CISC和RISC。
- 软件分类：系统软件（操作系统、语言处理程序）和应用软件；软件和硬件在逻辑上是等效的。

## 数据表示和运算
- 进制转换：二进制、八进制、十六进制、十进制之间的转换。
- 真值和机器数：把符号数字化的数叫机器数，机器数对应的实际数值叫真值。
- 原码：最高位是符号位，0表示正，1表示负，其余位是数值的绝对值。
- 反码：正数的反码和原码相同；负数的反码是符号位不变，其余位按位取反。
- 补码：正数的补码和原码相同；负数的补码是反码加1；补码的0表示唯一，可以多表示一个最小负数。
- 移码：把补码的符号位取反，用于表示浮点数的阶码，方便比较大小。
- 定点数：定点小数小数点固定在符号位后面，定点整数小数点固定在数值位最后。
- 浮点数：由阶码和尾数组成，阶码的位数决定浮点数的表示范围，尾数的位数决定浮点数的表示精度。IEEE754标准规定了浮点数的格式：1位符号位、8位阶码（移码表示）、23位尾数（隐含最高位1）。
- 定点加减运算：用补码进行运算，符号位和数值位一起参与运算；溢出判断：两个正数相加结果为负，或两个负数相加结果为正，就发生溢出。溢出判断方法：单符号位判断、双符号位判断。
- 移位运算：算术移位对有符号数，符号位不变；逻辑移位对无符号数，空位补0。
- 乘法运算：原码一位乘、补码一位乘(Booth算法)。
- 除法运算：原码恢复余数法、原码不恢复余数法(加减交替法)。
- ALU（算术逻辑单元）：实现算术运算和逻辑运算的组合逻辑电路，核心是加法器。
- 浮点数加减运算步骤：对阶（小阶向大阶看齐）、尾数求和、规格化（左规/右规）、舍入、溢出判断。

## 存储器层次结构
- 存储器层次结构：寄存器 → Cache → 主存 → 辅存；速度从快到慢，容量从小到大，单位价格从高到低。
- 存储器分类：
  - 按存取方式：随机存取存储器(RAM)、只读存储器(ROM)、串行访问存储器。RAM断电丢数据，ROM断电不丢数据。
  - 按在计算机中的作用：主存、辅存、Cache。
- 主存的基本组成：存储体、地址寄存器(MAR)、数据寄存器(MDR)、地址译码器、读写电路。MAR的位数决定寻址空间大小，MDR的位数等于存储字长。
- 半导体存储器：SRAM静态RAM，速度快，不需要刷新，用来做Cache；DRAM动态RAM，需要定时刷新，密度高，用来做主存。
- 主存地址空间分配：系统区（ROM）和用户区(RAM)；存储器与CPU的连接：地址线接地址引脚，数据线接数据引脚，读写信号接控制引脚。
- 双口RAM和多模块存储器：双口RAM有两个独立的读写端口，允许多个端口同时访问；多模块存储器交叉编址，提高数据带宽。
- Cache高速缓冲存储器：解决CPU和主存速度不匹配的问题，基于程序访问的局部性原理（时间局部性、空间局部性）工作，存放主存中CPU近期频繁访问的内容副本。
- Cache工作原理：CPU访问主存时，先看Cache中有没有对应内容，命中就直接从Cache读，不命中再访问主存并把内容调入Cache。
- Cache映射方式：
  - 直接映射：每个主存块只能固定放到一个Cache行，冲突率高，实现简单。
  - 全相联映射：每个主存块可以放到任意Cache行，冲突率低，比较电路复杂，成本高。
  - 组相联映射：折中方式，把Cache分成组，主存块映射到固定组，组内任意行。
- Cache替换算法：随机替换、先进先出(FIFO)、最近最少使用(LRU)。
- Cache写策略：写直达（写Cache同时写主存）、写回法（只写Cache，替换时才写回主存）。
- 虚拟存储器：由主存和辅存组成，由操作系统和硬件配合实现，给用户提供比实际主存大得多的逻辑地址空间，分为页式虚拟存储器、段式虚拟存储器、段页式虚拟存储器。TLB快表是页表的高速缓存，加快地址转换速度。

## 指令系统
- 指令是计算机执行操作的最小命令，一条指令由操作码和地址码组成。操作码说明做什么操作，地址码说明操作数的地址。
- 指令格式：零地址指令、一地址指令、二地址指令、三地址指令；地址码个数越多，指令长度越长，编程越灵活。
- 指令的寻址方式：
  - 立即寻址：地址码字段就是操作数本身，速度最快。
  - 直接寻址：地址码字段就是操作数的有效地址。
  - 间接寻址：地址码字段是操作数有效地址所在主存单元的地址。
  - 寄存器寻址：操作数在寄存器中，速度快。
  - 寄存器间接寻址：寄存器中放的是操作数的有效地址。
  - 基址寻址：基址寄存器内容加形式地址形成有效地址，适合多道程序。
  - 变址寻址：变址寄存器内容加形式地址形成有效地址，适合数组遍历。
  - 相对寻址：程序计数器PC内容加形式地址形成有效地址，适合转移指令。
- CISC复杂指令集：指令数量多，指令长度不固定，寻址方式多，代表是x86架构；指令系统复杂，硬件实现复杂。
- RISC精简指令集：指令数量少，指令长度固定，寻址方式少，大部分指令单周期完成，代表是ARM架构；指令系统简单，硬件实现效率高，适合流水线。

## CPU
- CPU的组成：运算器、控制器、寄存器组。运算器负责数据运算，控制器负责取指令、译码、发控制信号。
- CPU中的寄存器：
  - 通用寄存器：存放操作数。
  - 程序状态字寄存器(PSW)：存放程序状态标志。
  - 程序计数器(PC)：存放下一条要执行的指令地址，取指后自动+1。
  - 指令寄存器(IR)：存放当前正在执行的指令。
  - 地址寄存器(MAR)、数据寄存器(MDR)。
- 指令周期：取指令→间址→执行→中断，一个指令周期包含若干机器周期，一个机器周期包含若干时钟周期。
- 控制器的设计：硬布线控制器（组合逻辑电路实现，速度快，不灵活）和微程序控制器（把控制信号编成微程序存放在控制存储器中，灵活，速度慢）。
- 指令流水线：把一条指令的执行过程分成若干子过程，不同子过程重叠执行，提高指令吞吐率。流水线冒险包括结构冒险（硬件资源冲突）、数据冒险（指令间数据相关）、控制冒险（转移指令导致的）。
- 流水线性能指标：吞吐率、加速比、效率。流水线的加速比等于顺序执行时间除以流水线执行时间。

## 总线与I/O系统
- 总线是连接计算机各个部件的公共信息传输线，分为数据总线、地址总线、控制总线。数据总线宽度决定一次传输的数据位数，地址总线宽度决定寻址空间大小。
- 总线性能指标：总线宽度、总线带宽、总线复用、总线周转时间。
- 总线仲裁：集中仲裁（链式查询、计数器定时查询、独立请求）和分布仲裁。
- I/O接口：连接CPU和外部设备，实现数据缓冲、信号格式转换、控制定时。
- I/O控制方式：程序查询方式、中断驱动方式、DMA方式。DMA方式中，数据直接在设备和主存之间传输，不需要CPU干预。
- 中断系统：CPU收到中断请求后，暂停当前程序，转去执行中断服务程序，处理完后回到原程序继续执行。中断响应发生在每条指令执行周期结束后。中断处理过程：中断请求、中断响应、保护现场、中断服务、恢复现场、中断返回。
- 中断屏蔽：在中断屏蔽寄存器中设置屏蔽位，屏蔽某个中断请求，改变中断处理优先级。
