# 基于本地大模型的408知识点RAG检索问答系统
## 项目简介
这是一个完全离线运行、不依赖任何云端API的本地RAG（检索增强生成）问答系统，针对考研408计算机学科专业基础（数据结构、计算机组成原理、操作系统、计算机网络）构建专属知识库。系统全程在本地完成文档加载、文本切分、向量存储、相似性检索、大模型生成回答全流程，数据不出本机，无联网成本。
## 技术栈
- 大模型：Ollama + Qwen2.5:7B（本地部署）
- 向量模型：BGE-M3（本地文本嵌入）
- 向量检索：手写极简向量引擎（余弦相似度计算、本地JSON持久化）
- 后端框架：Flask
- 数据存储：SQLite（零配置存储问答历史）
- 前端：原生HTML/CSS/JS黑白极简交互界面
- 开发环境：Python 3.13
## 核心功能
1.  本地知识库：内置132个408核心知识点片段，细粒度切分保证检索精准
2.  离线问答：输入问题自动检索最相关知识点，拼接上下文调用本地大模型生成回答，全程不调用云端API
3.  智能刷题：自动生成408单选题，提交后自动判分并给出知识点解析
4.  历史记录：所有问答自动持久化存储，刷新页面不丢失
5.  实时状态：加载时显示实时思考计时，回答后展示总耗时

## 本地启动步骤
1.  安装Ollama客户端，拉取所需模型：
    ```bash
    ollama pull qwen2.5:7b
    ollama pull bge-m3
    ```
2.  创建Python虚拟环境，安装依赖：
    ```bash
    python -m venv venv
    pip install numpy ollama flask
    ```
3.  启动Web服务：
    ```bash
    python app.py
    ```
4.  浏览器访问 `http://localhost` 即可使用。
## 项目亮点
- 完全离线：所有模型和数据均在本地运行，无需联网、无API调用费用，隐私性强
- 自研核心组件：不依赖Chroma等现成向量库，从0手写实现向量编码、余弦相似度检索、本地持久化全流程
- 检索精准：细粒度切分知识点片段，测试5个典型问题全部精准召回
- 功能完整：覆盖问答复习、刷题检测、错题解析全学习闭环，是真的可用于复习的工具，不是演示demo
