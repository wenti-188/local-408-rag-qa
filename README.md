# 基于本地大模型的计算机专业复习与API开放平台
## 项目简介
这是一个完全离线运行、不依赖任何云端API的本地RAG应用，最开始针对408考研复习构建，现在已经扩充为覆盖计算机专业核心课程的随身复习助手。系统全程在本地完成文档加载、细粒度文本切分、向量存储、相似性检索、重排序、大模型流式生成回答，数据不出本机，无联网成本。
## 技术栈
- 大模型：Ollama + Qwen2.5:7B（本地部署）
- 向量模型：BGE-M3（本地文本嵌入）
- 向量检索：手写极简向量引擎（余弦相似度计算+关键词重排序+结果缓存、本地JSON持久化，完全不依赖Chroma等第三方向量库）
- 后端框架：Flask（复习页面） + FastAPI（API网关）
- 数据存储：SQLite（零配置存储问答历史、API Key、Token用量记录）
- 前端：原生HTML/CSS/JS，对齐DeepSeek极简交互风格，左侧边栏+居中聊天区布局，打字机流式输出、加载动画、实时思考计时
- 开发环境：Python 3.13
## 核心功能
1.  **全学科知识库**：共1820个细粒度知识片段，覆盖408四门课教材核心知识点、2021-2026年408统考真题、高频典型习题、互联网面试八股文、C/C++/Java/Python核心语法、MySQL数据库、Web开发、机器学习/深度学习基础概念。
2.  **离线问答**：输入问题自动检索Top-K最相关片段，结合关键词重排序优化召回结果，拼接上下文调用本地大模型流式逐字生成回答，全程不调用云端API，回答后自动展示总思考耗时。
3.  **Agent工具调用**：大模型自动判断问题场景，需要专业知识点解答时自动触发本地向量检索，通用闲聊直接应答，无需硬编码拼接上下文。
4.  **API开放平台**：基于FastAPI搭建标准REST接口，实现API Key鉴权、Token消耗自动统计，每次调用自动记录用户的prompt、生成段Token用量，支持在开发者控制台可视化查询累计调用次数与Token消耗，提供在线接口测试能力。
5.  **智能刷题**：基于导入的历年真题自动生成变体单选题（微调题目数字/条件，不照抄原题），提交后自动判分并给出知识点解析。
6.  **交互体验**：对齐DeepSeek极简界面风格，左侧边栏包含新建对话、最近对话列表、功能入口；空状态提供分类快捷问题卡片，点击直接提问；多行输入框支持Enter发送、Shift+Enter换行，自动调整输入高度；所有等待操作都有加载动画提示，流式打字机输出，历史记录自动持久化，刷新页面自动加载历史对话。
## 手写向量引擎特性
-  从0实现文本嵌入调用、余弦相似度Top-K检索、JSON本地持久化
-  融合向量语义相似度与关键词匹配的综合打分机制，优化召回精准度
-  内置查询结果缓存，重复问题无需重复计算，响应更快
-  启动时自动加载本地持久化向量库，无需重复计算所有文本的向量

## 本地启动步骤
1.  安装Ollama客户端，拉取所需模型：
    ```bash
    ollama pull qwen2.5:7b
    ollama pull bge-m3
    ```
2.  创建Python虚拟环境，安装依赖：
    ```bash
    python -m venv venv
    pip install numpy ollama flask fastapi uvicorn langchain langchain-ollama
    ```
3.  启动复习页面服务（80端口）：
    ```bash
    python app.py
    ```
4.  启动API网关服务（8000端口）：
    ```bash
    python api_server.py
    ```
5.  访问 http://localhost 使用复习功能，访问 http://localhost:8000 打开开发者控制台。
## 项目亮点
- 完全离线：所有模型和数据均在本地运行，无需联网、无API调用费用，隐私性强
- 自研核心组件：不依赖Chroma等现成向量库，从0手写实现文本嵌入、余弦相似度检索、重排序、结果缓存、本地持久化全流程
- 完整平台能力：从RAG检索到API网关、鉴权、Token统计、开发者控制台，覆盖大模型应用从模型部署到开放接口的全链路
- 实用导向：知识库覆盖考研、实习面试所需的核心计算机知识点，不是演示Demo，是日常复习真的能用的工具
