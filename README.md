# 基于本地大模型的408知识点RAG检索问答系统
## 项目简介
这是一个完全离线运行、不依赖任何云端API的本地RAG（检索增强生成）问答系统，针对考研408计算机学科专业基础（数据结构、计算机组成原理、操作系统、计算机网络）构建专属知识库。系统全程在本地完成文档加载、细粒度文本切分、向量存储、相似性检索、重排序、大模型流式生成回答全流程，数据不出本机，无联网成本。
## 技术栈
- 大模型：Ollama + Qwen2.5:7B（本地部署）
- 向量模型：BGE-M3（本地文本嵌入）
- 向量检索：手写极简向量引擎（余弦相似度计算+关键词重排序+结果缓存、本地JSON持久化，完全不依赖Chroma等第三方向量库）
- 后端框架：Flask + 多线程流式响应
- 数据存储：SQLite（零配置存储问答历史）
- 前端：原生HTML/CSS/JS黑白极简交互，打字机流式输出、跳动加载动画、实时思考计时
- 开发环境：Python 3.13
## 核心功能
1.  本地知识库：内置303个细粒度50-80字知识点片段，覆盖四门课核心概念、2021-2026年408高频真题考点，细粒度切分保证检索精准
2.  离线问答：输入问题自动检索Top-K最相关片段，结合关键词重排序优化召回结果，拼接上下文调用本地大模型流式逐字生成回答，全程不调用云端API，回答后自动展示总思考耗时
3.  智能刷题：基于导入的历年真题自动生成变体单选题（微调题目数字/条件，不照抄原题），提交后自动判分并给出知识点解析
4.  历史记录：所有问答自动持久化存储，刷新页面后自动加载历史对话，相同问题命中本地缓存直接返回，二次响应速度提升一倍
5.  交互优化：加载时显示跳动动画提示，流式打字机输出效果，全局异常捕获友好提示，纯黑白极简无冗余界面
## 手写向量引擎特性
-  从0实现文本嵌入调用、余弦相似度Top-K检索、JSON本地持久化
-  融合向量语义相似度与关键词匹配的综合打分机制，优化召回精准度
-  内置查询结果缓存，重复问题无需重复计算，响应更快
-  启动时自动加载本地持久化向量库，无需重复计算303条文本的向量

## 本地启动步骤
1.  安装Ollama客户端，拉取所需模型：
    ```bash
    ollama pull qwen2.5:7b
    ollama pull bge-m3
    ```
2.  创建Python虚拟环境，安装依赖：
    ```bash
    python -m venv venv
    pip install numpy ollama flask
    ```
3.  启动Web服务：
    ```bash
    python app.py
    ```
4.  浏览器访问 `http://localhost` 即可使用。
## 项目亮点
- 完全离线：所有模型和数据均在本地运行，无需联网、无API调用费用，隐私性强
- 自研核心组件：不依赖Chroma等现成向量库，从0手写实现文本嵌入、余弦相似度检索、重排序、结果缓存、本地持久化全流程
- 检索精准：细粒度切分知识点片段，融合语义相似度与关键词匹配的综合打分机制，典型问题全部精准命中
- 体验完整：覆盖知识点问答、真题考点匹配、变体刷题全学习闭环，是可直接用于408备考的实用工具，不是演示Demo
